# Next Level Gaming & Esports Arena - Mobile App

## Description

The Next Level Gaming & Esports Arena mobile application is an Android application designed for customers of a gaming and esports arena in Johannesburg.

The application allows users to explore gaming packages and experiences, view package details, make bookings, receive quotations, manage their bookings, and manage their profile.

The app provides a convenient way for customers to interact with the gaming arena without needing to visit the venue or make all enquiries manually.

## Features

- Splash screen
- User login
- User registration
- Home screen
- View gaming packages
- View package details
- View gaming experiences
- View experience details
- Make bookings
- Calculate and view quotations
- View existing bookings
- Manage user profile

## Installation

1. Download or clone the project.
2. Open Android Studio.
3. Select "Open" and choose the NextLevelGaming project folder.
4. Allow Android Studio to load and synchronise the Gradle files.
5. Make sure the required Android SDK is installed.
6. Create or connect an Android device/emulator.
7. Click the Run button in Android Studio.
8. Select the Android device or emulator.
9. Wait for the application to build and launch.

## Usage

1. Launch the Next Level Gaming & Esports Arena application.
2. View the splash screen.
3. Log in or register for an account.
4. Browse the available gaming packages.
5. Select a package to view its details.
6. Browse the available gaming experiences.
7. Select an experience to view more information.
8. Make a booking.
9. View the quotation for the booking.
10. View and manage bookings from the My Bookings section.
11. Manage account information from the Profile section.
